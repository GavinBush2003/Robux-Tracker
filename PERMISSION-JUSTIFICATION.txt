alarms: Used for an optional background sync. If the user turns it on in the extension's settings, an alarm wakes the extension every few hours to refresh the user's own Robux transaction history while a roblox.com tab is open. It is off by default and does nothing otherwise.

storage: Saves one small setting (whether background sync is on and how often) so the extension's background script can read it. No transaction data or personal data is stored with this permission.

Host permissions:
economy.roblox.com - reads the user's own transaction history and Robux balance. This is the extension's core function.
users.roblox.com - confirms which account is signed in, so saved results are never mixed between accounts.
thumbnails.roblox.com - fetches game, item and avatar icons.
www.roblox.com and web.roblox.com (content script) - adds the Robux Tracker entry to the Roblox sidebar and shows the panel on the page.

Everything is stored locally in the user's browser. Nothing is sent anywhere except these Roblox requests, and the extension only reads data.
